## 📋 Project Overview

A full-stack web application for managing Information Security in a banking environment, built as part of an internship at **Equity Bank Rwanda PLC**.  
Aligned with **ISO/IEC 27001:2022** — the international standard for Information Security Management Systems.

---

## 🛡️ Modules

| Module | Description |
|--------|-------------|
| 🏠 Dashboard | Real-time KPIs, risk overview, security score |
| ⚠️ Risk Assessment | Risk register, heatmap, treatment tracking |
| 🚨 Incident Response | Incident lifecycle, severity management, regulatory timelines |
| 🔐 Access Control | User management, access reviews, privileged access |
| 🔒 Encryption & Policies | Policy library, encryption asset tracker, acknowledgments |
| 📋 Audit Logs | Activity monitoring, SIEM alerts, compliance reports |
| 🎓 Security Training | Course management, completion tracking, phishing simulations |

---

## 🛠️ Tech Stack

- **Frontend**: Next.js 14 (App Router) + TypeScript
- **Database**: PostgreSQL (Supabase)
- **ORM**: Prisma 7
- **Auth**: NextAuth.js v5
- **Charts**: Recharts
- **Animations**: Framer Motion
- **Icons**: Lucide React

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Set up environment variables
cp .env.example .env
# Fill in your DATABASE_URL and NEXTAUTH_SECRET

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.
